# 结果核验与冻结

## 两类结果

```text
results/raw/       未审核、中间或失败结果
results/verified/  已核验、可用于论文和正式绘图的结果
```

## 进入 verified 的条件

结果至少应满足：

1. 来源代码和命令明确；
2. 数据版本明确；
3. 参数与随机种子明确；
4. 指标计算方法明确；
5. 与日志和报告一致；
6. 必要时已重复运行或人工抽查；
7. 没有数据泄漏或手工填写数字；
8. 已通过对应 Gate 的核验要求。

## 结果登记

维护：

```text
results/verified/result_registry.md
```

建议字段：

| Evidence ID | Claim | Source | Command | Verified | Notes |
|---|---|---|---|---|---|

## 禁止事项

- 直接手改正式 CSV 数字；
- 从 `raw/` 中挑一个最好结果写论文；
- 图、表、摘要使用不同版本；
- 无来源地复制数字；
- 修改模型后继续沿用旧结果。

## 结果失效

模型、数据或指标变化后，应重新核验相关 Evidence，并标记旧结果失效。

> 后续可增加自动一致性检查和哈希记录。
