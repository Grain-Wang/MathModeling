# 最终提交检查清单

以 `competition/` 中当届官方要求为最高标准。

## 1. 题目与内容

- [ ] 全部小问均已明确作答
- [ ] 模型假设、变量和单位完整
- [ ] 公式与代码实现一致
- [ ] 结论没有超出证据
- [ ] 局限和适用范围如实说明

## 2. 数据与结果

- [ ] 论文数字均来自 `results/verified/`
- [ ] 表格、图片和摘要数字一致
- [ ] Evidence registry 可追溯
- [ ] 关键结果已抽查或复现
- [ ] 不存在测试集泄漏或人工填写结果

## 3. 图表与论文

- [ ] 图题、表题、坐标轴和单位完整
- [ ] 图片清晰且未误导
- [ ] 符号和术语前后一致
- [ ] 摘要包含主要方法和定量结果
- [ ] 引用和参考文献格式正确

## 4. 合规

- [ ] 使用正确官方模板
- [ ] 文件名、匿名、页数和格式满足要求
- [ ] AI 使用记录符合当届规则
- [ ] 没有泄露个人或学校身份信息
- [ ] 提交包不含无关临时文件

## 5. 版本与备份

- [ ] G6 已 PASS
- [ ] 最终 PDF 已人工打开检查
- [ ] 最终提交文件已备份
- [ ] 已创建最终 Git commit / tag
- [ ] 提交后保存回执或截图

> 后续可根据正式通知增加逐项官方检查要求。
