# 常用预测评价指标（Prediction Metrics）

## 1. 适用问题

适用于回归、分类和概率预测的模型比较与验收。指标必须由任务代价、类别分布、预测尺度和决策阈值决定；至少配一个可解释 Baseline，必要时同时报告互补指标。

## 2. 不适用或需谨慎的情况

单一平均指标会掩盖关键子群和极端时期。类别不平衡时准确率可能无效；响应含零或接近零时 MAPE 不稳定；$R^2$ 不能跨不同测试集随意比较，也不直接代表误差量级。

## 3. 核心思想

先把业务损失翻译成评价量，再在完全未参与拟合的数据上计算。点预测评价误差大小，概率预测还需评价区分度与校准；阈值型指标必须说明阈值来源。

## 4. 基本数学形式

回归常用

$$
MAE=\frac1n\sum_i|y_i-\hat y_i|,\qquad
RMSE=\sqrt{\frac1n\sum_i(y_i-\hat y_i)^2}。
$$

分类中 $Precision=TP/(TP+FP)$、$Recall=TP/(TP+FN)$。概率二分类的对数损失同时惩罚错误和过度自信。

## 5. 输入、输出与主要假设

输入为独立测试标签、点预测或概率、样本权重和预先定义的聚合方式；输出为总体与分组指标、区间和逐样本损失。假设测试分布及权重能代表目标应用，标签质量可靠。

## 6. 标准建模流程

确定决策成本和主要指标；建立均值/中位数、朴素时序或多数类 Baseline；锁定切分；保留逐样本预测；计算主指标、辅助指标和子群结果；仅用验证集选阈值；最终测试一次并报告不确定性。

## 7. 评价与验证方式

用交叉验证、滚动回测或独立测试集；通过 Bootstrap 给指标差异区间；分类查看混淆矩阵、PR/ROC 与校准曲线，回归查看残差随预测值、时间和子群变化；检查排名对指标选择是否敏感。若最终决策有明确收益和代价，还应在验证集上画成本随阈值变化的曲线，并与“不采取行动”等现实策略比较。

## 8. 优点

明确指标能把算法比较转化为可复核证据。多个互补视角可区分平均准确、尾部风险、区分能力和概率可信度。

## 9. 局限

所有指标都会压缩信息，并隐含错误成本。对同一测试集反复选模型会造成选择偏差；指标改善也不保证部署后产生实际收益。

## 10. 华为杯常见用法

预测题应按题意指定主指标，并与简单 Baseline 同表展示。对地区、时段或重要类别给分组误差；若指标来自题目官方规则，须完全复现其聚合和权重。

## 11. 常见误用

不平衡分类只报准确率；回归只报 $R^2$；在测试集调阈值；挑选最有利指标；对时间序列随机切分；只给点估计不报告折间波动；把训练分数当泛化性能。

## 12. Python 实现建议

使用 scikit-learn `metrics` 与 `model_selection`。注意 scorer 中“越大越好”的符号约定、概率与标签接口差异及 `average` 参数；保存 `y_true`、`y_pred`、折号和样本 ID 以便复核。
