# Bootstrap 重采样（Bootstrap Resampling）

## 1. 适用问题

适用于解析标准误或区间难以获得、统计量分布复杂时估计不确定性，例如中位数、指标差、模型性能和排名稳定性。也适合小型仿真式稳健性检查。

## 2. 不适用或需谨慎的情况

样本不能代表总体、样本极小、统计量不规则，或观测存在时间、空间、簇内依赖时，普通独立同分布重采样会失真。稀有类别可能在重采样中消失，外推不确定性也无法由样本内 Bootstrap 修复。

## 3. 核心思想

把经验分布当作未知总体的近似，从原样本有放回抽取许多同规模样本，重复计算统计量，以其经验分布近似抽样分布。简单场景先用解析区间作 Baseline，再判断重采样是否必要。

## 4. 基本数学形式

对 $B$ 个重采样统计量 $\hat\theta^{*(b)}$，标准误估计为

$$
\widehat{SE}_{boot}=\sqrt{\frac{1}{B-1}\sum_{b=1}^{B}
(\hat\theta^{*(b)}-\bar\theta^*)^2}。
$$

百分位区间取其经验分位数；偏差明显时可考虑 BCa，但需说明实现与条件。

## 5. 输入、输出与主要假设

输入为代表性样本、统计量函数、重采样单位和次数；输出为标准误、区间或稳定性分布。关键假设是重采样单位正确，独立情形下观测近似同分布；簇或时序数据要改为簇 Bootstrap 或块 Bootstrap。

## 6. 标准建模流程

明确估计对象；选择观测、主体或时间块为抽样单位；固定随机种子；逐步增加 $B$ 检查 Monte Carlo 稳定性；计算区间并与解析或置换结果比较；记录失败拟合和有效次数。

## 7. 评价与验证方式

画重采样分布并检查偏态、异常和区间稳定性；在可模拟数据上评估区间覆盖率；改变 $B$、块长度或分层方案做敏感性分析；预测性能必须在每次重采样内部重拟合完整管道。若比较两个模型，应在同一批重采样数据上计算成对指标差，避免额外抽样噪声掩盖差异。

## 8. 优点

方法通用，对复杂统计量所需推导较少，能直观呈现估计不确定性和排名波动。

## 9. 局限

计算量可能很大；结果不能超越原样本信息。错误的重采样单位会给出非常精确但错误的区间，某些边界参数和极端分位数下近似也较差。

## 10. 华为杯常见用法

用于评价指标置信区间、方案排名稳定性、回归系数和仿真输出不确定性。应说明重采样单位、次数、区间类型和随机种子。

## 11. 常见误用

对时间序列逐点随机抽样；只重采样预测值而不重拟合模型；把重采样次数当有效样本量；挑选有利的区间方法；忽略某些样本导致模型无法拟合的情况。

## 12. Python 实现建议

简单统计量可用 `scipy.stats.bootstrap`；复杂管道自行封装重采样循环。分层、簇或块 Bootstrap 要显式实现正确索引；并行运行时为每个任务生成独立随机数流。
