## 3. 公平比较不变量

1. 所有选择只使用附件一与已冻结 `condition_group`/`near_shape_group` 折；不能重新随机划分。
2. Q2/Q4 候选与 Baseline 使用相同 OOF 行、同一主指标公式和同一主要子组定义。
3. HGB 调参只在各外层训练折内的固定内3折完成；外层验证折不参与选择。
4. Q5 只消费最终 Q4 胜者的严格 OOF 分数；full-fit 只作参考与部署模型，不参与主 Pareto 评分。
5. 负结果、触发的回退和未运行的条件挑战者都写入报告，不以事后扩大搜索修饰结论。
