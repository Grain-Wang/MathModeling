# Q5 Model Contract — 磁性元件双目标优化

## Problem

以 Q4 冻结损耗预测模型为损耗目标，同时最大化题目指定的传输磁能代理 $E=fB_m$，在温度、频率、波形、磁通密度峰值和材料上给出可执行的权衡条件。

## Inputs

- Q4 冻结 Pipeline、特征 schema、全量模型和外层折模型；
- 附件一满足可行域规则的实测行及其完整波形；
- $T,f,w,B_m,m$ 和 `condition_group`；
- Q4 OOF 误差、子组指标和失败状态。

不使用附件二；附件三不用于构造优化域或评价最优解。

## Outputs

- 两目标数学模型和可行候选集合；
- 非支配 Pareto 集及每个候选的 $T,f,w,B_m,m,\widehat P_v,E$；
- 最小预测损耗端点、最大 $E$ 端点和一个有明确规则的膝点；
- 各候选跨 Q4 折模型的 Pareto 入选频率和损耗区间；
- 题面名义频率域、实测边界域和峰值口径的敏感性结果；
- 若不稳定，则只给候选区域而不给唯一“最优”。

## Variables and Units

| Variable | Type | Domain / Unit |
|---|---|---|
| $T$ | 离散决策 | {25,50,70,90} °C |
| $f$ | 连续决策的实测候选值 | 主结果 50,000–500,000 Hz |
| $w$ | 离散决策 | 正弦波、三角波、梯形波 |
| $B_m$ | 连续决策的实测候选值 | T，主口径 `max(abs(B))` |
| $m$ | 离散决策 | 材料1–4 |
| $\widehat P_v(x)$ | Q4 预测损耗目标 | W/m³，最小化 |
| $E(x)=fB_m$ | 题目传输磁能代理 | Hz·T，最大化 |

## Assumptions

1. 附件一实测状态是最可信的联合可行域代理；不把逐变量边界的任意组合假设为可行。
2. Q4 在候选邻域有足够预测能力；其误差必须传播到优化稳定性。
3. $fB_m$ 只是题目规定的代理，不包含磁芯尺寸、饱和、温升、成本等真实约束。
4. 多目标没有题面给定权重，因此 Pareto 集优先于主观加权和。
5. 实测行枚举能回答“在已有数据支持下什么条件更优”，但不证明连续物理空间全局最优。

## Mathematical Definition

主可行集合：

\[
\mathcal X_{obs}=\{x_i\in\text{附件一}:50000\le f_i\le500000\},
\]

其中完全相同状态折叠一次，每个 $x_i$ 保留真实完整波形供 Q4 计算。双目标统一写成最小化：

\[
F(x)=\left(F_1(x),F_2(x)\right)
=\left(\widehat P_v^{(Q4)}(x),-f(x)B_m(x)\right).
\]

若 $F_1(a)\le F_1(b)$ 且 $F_2(a)\le F_2(b)$，至少一个严格不等，则 $a$ 支配 $b$。Pareto 集为不被任何候选支配的集合。

膝点规则：分别按 Pareto 集的最小/最大值把 $\widehat P_v$ 和 $-E$ 线性归一化到 $[0,1]$，选择到理想点 $(0,0)$ 欧氏距离最小者；若并列，先选预测不确定性较小者，再按 `row_id` 稳定排序。该规则不代表用户偏好，只提供代表性折中。

## Objective

找到损耗预测与 $fB_m$ 之间的非支配权衡，并优先保留在 Q4 误差、峰值定义和频率边界扰动下仍稳定的候选。

## Constraints

1. Q4 未冻结或未通过最低预测能力检查时，不给正式 Q5 推荐。
2. 主候选必须来自 `X_obs`，材料/温度/波形只能取实测类别。
3. 每个候选的全部 Q4 输入必须真实存在；不能只给 $B_m$ 而凭空补齐波形特征。
4. 主结果排除题面频率外的 49,990 或 501,180 Hz 行；这些只进入边界敏感性。
5. 不使用观测 $P_v$ 代替题目要求的 Q4 目标；观测值只用于检查 Q4 候选处残差。
6. 不用附件三分布调整可行域、权重或膝点。
7. 输出不得称为真实工程全局最优。

## Parameters

| Parameter | Frozen value |
|---|---|
| 主可行域 | 附件一实测行且 50–500 kHz |
| 边界敏感域 | 附件一全部实测 49.99–501.18 kHz |
| 峰值敏感口径 | `B_pp/2` |
| uncertainty seed | `20240922` |
| Pareto membership threshold | 稳定推荐至少 50% 折模型入选 |
| knee tie break | 不确定性较小，再按 `row_id` |

## Training / Solving Procedure

1. 核验 Q4 冻结状态、主指标和子组失败条件；若失败，停止正式优化。
2. 从附件一构造名义频率主候选集，折叠完全重复状态并保留来源 `row_id`。
3. 用 Q4 全量冻结模型计算点预测 $\widehat P_v$，计算 $E=fB_m$。
4. 向量化执行非支配筛选，输出 Pareto 集和两个端点、膝点。
5. 用每个 Q4 外层折模型重复预测和 Pareto 筛选；记录候选入选频率、预测中位数和 2.5%/97.5% 分位。
6. 用每行 Q4 OOF 预测与实测 $P_v$ 检查 Pareto 邻域残差，不把训练内拟合值当验证。
7. 分别切换到实测边界域和 `B_pp/2` 口径重算，比较端点、膝点和因素条件是否变化。
8. 若满足连续扩展进入条件，可在 S4 新建明确修订合同；否则主结论止于实测域。

## Baseline

在 `X_obs` 上直接枚举 Q4 预测目标并做严格非支配排序。这是可在 S3 快速完成的完整路线，不需要遗传算法或粒子群。

对照基准为：

- 只最小化 $\widehat P_v$；
- 只最大化 $E$；
- Pareto 膝点。

## Evaluation

- 可行性：所有候选来自附件一真实行，字段和 Q4 特征完整；
- 非支配性：程序化两两/排序断言，Pareto 点不被集合内其他点支配；
- 预测可靠性：Pareto 候选的 Q4 OOF 残差和所属子组误差；
- 稳定性：跨 Q4 折模型的 Pareto 入选频率，端点/膝点条件一致性；
- 敏感性：题面/实测频率域、`B_m`/`B_pp/2`、保留/折叠重复；
- 简单策略比较：两个单目标端点与膝点的目标损失；
- 复现：相同模型/候选哈希下输出排序和 CSV 哈希一致。

## Failure Conditions

- Q4 未优于常数或分组中位数 Baseline；
- Q4 在 Pareto 候选所属子组有非有限、非正或明显失准预测；
- 候选不是实测联合状态，或缺失 Q4 所需波形特征；
- Pareto 实现返回被支配点或归一化零范围未处理；
- 代表候选跨折模型入选率 <50%，或峰值/频率口径改变后条件完全反转；
- 推荐点只在误差最大的边界/稀疏子组出现；
- 把 $fB_m$ 称为实际传输磁能或宣称全局物理最优；
- 为获得连续最优而临时引入无验证启发式算法。

失败时只报告稳定的 Pareto 区域、两个端点和不确定性；不强行给唯一推荐。连续搜索不是完成本问的必要条件。
