## 4. 冻结与变更规则

1. 本表在 G1 审核快照中是需求基线；Reviewer PASS 前不得进入 S2。
2. S2 模型合同必须逐项引用 R1.1–R5.2，不能用代理任务替换题目输出。
3. 若后续发现题意或字段口径错误，先记录决策和影响，再更新矩阵并按 Gate 规则复审。
4. `results/raw/` 中的审计统计不是正式模型结果；问题结论和论文图表只能在相应阶段从核验后的证据生成。

结论：`[INFERENCE]` 所有题面要求均已映射到输出、数据和至少一种初步验证证据；当前没有未映射的主要小问。该结论仍需 G1 Reviewer 独立确认。
