## 2. Q2：二次乘性温度修正

固定形式为：

\[
\log P=\log k+\alpha\log f+\beta\log B_m+\gamma_1 z+\gamma_2z^2,
\qquad z=(T-25)/65.
\]

它等价于传统 Steinmetz 方程乘以 `exp(gamma1*z+gamma2*z^2)`，只新增冻结的二次温度修正，不做逐步项搜索。

| 指标 | 传统 Steinmetz | 二次温度修正 | 变化 |
|---|---:|---:|---:|
| OOF RMSLE | 0.360678 | 0.202567 | 改善 43.84% |
| OOF MAPE | 32.53% | 16.21% | 降低 16.32 个百分点 |
| 原尺度 R² | 0.9412 | 0.9753 | +0.0341 |

采用条件为“总体 RMSLE 下降且至少 3/4 温度不劣化”，实际为 3/4，通过。50°C 的分温度 OOF RMSLE 从 0.12065 升至 0.12796（劣化 6.06%），必须作为局部负结果保留。

留一温度压力中，25°C 从 0.62624 降至 0.22788，90°C 从 0.55430 降至 0.30606；70°C 也改善，50°C 从 0.13438 升至 0.14378。`B_pp/2` 口径相对 RMSLE 只变化 +0.36%，精确去重变化为 0，没有结论反转。因此采用二次温度修正，不触发 `EXP-Q2-EXT-001` 的条件交互扩展。

## 3. Q4：HGB 主模型、消融与压力

`EXP-Q4-MAIN-001` 在每个外层训练折内部，用固定内3折从冻结的 18 个 HGB 候选中选择参数，再在原外层验证折评分。与 Ridge 使用完全相同的 12,400 行、5 个外折和 RMSLE 定义。

| 模型 | 数值特征 | OOF RMSLE | MAPE | 原尺度 R² |
|---|---:|---:|---:|---:|
| Ridge Baseline | 48 | 0.200097 | 15.85% | 0.9507 |
| HGB 完整 wave-v1 | 48 | 0.076397 | 5.87% | 0.9948 |
| HGB 工况+幅值（最终） | 18 | 0.070941 | 5.48% | 0.9952 |
| HGB 工况-only 消融 | 2 | 0.143829 | 9.31% | 0.9897 |

完整 HGB 相对 Ridge 改善 61.82%，所有主要子组中的最大相对变化仍为改善 50.64%，通过“总体改善≥2%、任何主要子组恶化≤10%”的替换门槛，因此不触发 RandomForest 挑战者。

消融复用各外折已经选定的参数，不重新调参。去掉 30 个 shape 特征后，18 个工况+幅值特征比完整模型再改善 7.14%；按冻结规则“无增益特征组删除”，最终 Q4 冻结为 `HGB + amplitude_and_condition`。其低 `B_m` 四分位 RMSLE=0.08328，显著低于 Ridge 的 0.25751。

压力测试显示外推仍是主要限制：留一材料最差 RMSLE=0.37982（材料1），留一温度最差 RMSLE=0.57496（25°C）。这些数值是未见水平外推压力，不替代主 OOF 指标；论文必须限定模型更适合已覆盖材料和温度水平内的插值预测。

## 4. Q3：预定义两两交互与簇 Bootstrap

交互模型只增加冻结的三组交互：温度×波形、温度×材料、波形×材料；工况样条、外层折和内层选参协议与加性 Baseline 一致。

| 指标 | 加性模型 | 两两交互模型 | 变化 |
|---|---:|---:|---:|
| OOF log-RMSE | 0.343416 | 0.326667 | 改善 4.88% |
| 原尺度 R² | 0.6036 | 0.5941 | 局部权衡，略降 |

主指标改善，故采用交互模型。500/500 次 `condition_group` 簇 Bootstrap 有效；40 个两两水平对比中 27 个符号稳定度≥0.90。调整后最低损耗组合在 500 次中均为 `90°C / 正弦波 / 材料1`，但这只是控制 `f/B_m` 后、在观测支持内的关联结果，不是因果结论，也不是 Q5 的唯一最优工况。

共同矩形支持仍只有 1,766 行（14.24%）；在共同支持内交互模型相对加性模型改善 2.14%。改用 `B_pp/2` 后 log-RMSE 相对变化 +2.28%，精确去重变化 +0.004%。报告时只使用在 Bootstrap 与支持分析中稳定的调整后关联；13 个符号稳定度不足 0.90 的对比不作强结论。

## 5. Q5：最终胜者驱动的稳定性闭环

Q5 消费 Q4 最终 `HGB + amplitude_and_condition` 的严格 OOF 预测。逐折重新核验训练/验证 `condition_group` 哈希和模型 ID；12,236 个去重候选均具备严格 OOF 谱系。

| 项目 | S4 结果 |
|---|---:|
| 严格 OOF Pareto 点 | 118 |
| full-fit 参考 Pareto 点 | 122 |
| 观测损耗诊断 Pareto 点 | 130 |
| 至少 3 折支持区域 | 27 |
| 500 次 Bootstrap 稳定区域 | 42 |
| 折支持后模型区域 vs 观测区域 Jaccard | 0.39535 |
| 冻结门槛 | 0.50 |
| 单点合格数 | 0 |

500/500 次工况组重采样均完成，但其含义只限于“固定交叉拟合候选表的重采样稳定性”，不声称覆盖完整模型参数不确定性。主 Jaccard 从 S3 Ridge 的 0.0962 提高到 0.3953，仍未过 0.50；因此 `unique_recommendation_authorized=false`。

不施加折级稳定过滤时，三个敏感性场景的 OOF 区域相对主口径 Jaccard 最低为 0.881，宽频率和保留重复均为 1.0，`B_pp/2` 为 0.881。该敏感性稳定不能覆盖主 Gate 的失败；只能报告 Pareto 区域、端点和临时膝点，禁止给唯一工况。

## 6. Q1：保留简单模型

基于附件一原始 1024 点波形实际重算变换后 shape-v1 特征：循环相移 137 点、幅值×0.5、幅值×2.0 的预测与 Baseline 一致率均为 1.000；留一材料的最低 Macro-F1 也为 1.000。时间域-only 与频域-only 消融均达到 Macro-F1=1.000，而辅助字段-only 仅为 0.41976。

因此保持 shape-only Logistic。没有运行 HGB/RandomForest 分类器，因为强制压力后仍无可测的选择空间；增加复杂度不能形成可验证收益。完美 OOF 仍只说明附件一的三类形状高度可分，不等价于附件二未知真值上的 100% 准确率。
