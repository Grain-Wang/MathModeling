## 1. 方案目标与阶段边界

本方案把五问组织成同一条可复现证据链：

```text
只读原件 + manifest SHA-256
        ↓
统一样本表、字段和波形特征（同一 feature_version）
        ↓
先冻结分组折与评价指标，再训练
        ├─ Q1 波形形状分类 ──> 附件二冻结预测
        ├─ Q2 Steinmetz Baseline ──> 温度修正与公平误差比较
        ├─ Q3 控制 f/B_m 后的三因素主效应和两两交互
        └─ Q4 全工况损耗预测 ──> 附件三冻结预测
                                   ↓
                      Q5 用 Q4 模型在联合数据支持域求双目标 Pareto
```

S2 只定义合同和实验计划，不生成训练分数、附件预测或“最优”工况。G2 PASS 后先在 S3 完成全部 Baseline 闭环；只有满足预先定义的进入条件，才在 S4 执行有限的主模型改进。

## 2. 全题统一数据合同

### 2.1 数据角色

| 数据 | 允许用途 | 禁止用途 |
|---|---|---|
| 附件一 | 特征、训练、内部验证、因素分析、Q5 联合支持域 | 未记录删样本；全数据预处理后再切分 |
| 附件二 | Q1 模型和预处理完全冻结后的最终分类 | 特征选择、调参、模型选择、精度声明 |
| 附件三 | Q4 模型和预处理完全冻结后的最终损耗预测 | 特征选择、调参、模型选择、精度声明 |
| 附件四 | 复制后写入冻结的 Q1/Q4 结果 | 覆写 `src/` 原件；当作 Ground Truth |

所有学习型变换只在训练折拟合。折号、样本行号、原始文件 SHA、配置、命令和输出路径进入实验日志。附件二、三不进入任何交叉验证对象。

### 2.2 统一量纲与派生量

对每条 1,024 点磁通序列 $B_0,\ldots,B_{1023}$，冻结：

\[
\bar B=\frac1{1024}\sum_j B_j,\quad
B_m=\max_j|B_j|,\quad
B_{pp}=\max_j B_j-\min_j B_j,
\]

\[
B_{rms}=\sqrt{\frac1{1024}\sum_j B_j^2},\quad
\Delta B_j=B_{(j+1)\bmod 1024}-B_j.
\]

- `B_m` 主口径为 `max(abs(B))`，单位 T，全题 Q2/Q4/Q5 一致。
- `B_pp/2` 作为峰值口径敏感性，不替换主口径；若二者相对差超过 1%，必须报告影响。
- $f$ 保留实测 Hz；训练和预测均不静默裁剪。
- Q5 主结果采用题面名义范围 $50{,}000\le f\le500{,}000$ Hz，49,990–501,180 Hz 实测边界只进入敏感性版本。
- 损耗 $P_v>0$，单位 W/m³；传输磁能代理 $E=fB_m$，单位 Hz·T，不称为真实磁能。

### 2.3 波形特征版本 `wave-v1`

`wave-v1` 只由预测时可获得的 $B_j$ 计算：

1. 幅值：$B_m$、$B_{pp}$、$B_{rms}$、峰均比；
2. 位置无关分布：均值、标准差、分位数、偏度和峰度；
3. 周期差分：最大/平均绝对斜率、斜率分位数、总变差、正负斜率比例；
4. 平台/转折：以 `0.05 × max(abs(ΔB))` 为固定阈值的平台比例、斜率符号变化数；
5. 频域形状：去均值后的 FFT 幅值，基波及第 2–10 次谐波相对能量、总谐波比；
6. Q1 形状归一化：$(B_j-\bar B)/B_{pp}$，不把温度、频率或材料作为主分类特征。

所有阈值和数值保护写入配置。若 $B_{pp}=0$ 或基波能量低于机器容差，流水线报错而不是产生无穷值；S1 已确认没有平坦波形。

## 3. 重复与验证分组合同

### 3.1 完全重复

S1 发现材料3有 1 条额外完全重复记录。主流程保留原始行，但相同完整记录必须分到同一折；训练时不因重复而复制到不同折。S4 做“保留 vs 去除一条”的敏感性实验，若关键指标或结论改变超过预设阈值，则升级为数据处理 Major 风险。

### 3.2 近重复形状签名

在任何模型拟合前，按以下固定步骤形成 `near_shape_group`：

1. 去均值并除以 $B_{pp}$；
2. 循环平移，使第一次达到全局最大值的位置为索引 0；
3. 将 1,024 点分成 64 个连续块并取块均值；
4. 以 0.02 为步长量化后生成 SHA-256。

若某一波形类别不足 5 个不同组，只把量化步长依次改为 0.01、0.005；仍不足时退回精确波形指纹，并在日志中记录。该回退只依据组数量和类别覆盖，在任何模型评分前执行。

### 3.3 工况组

冻结固定物理分箱：

\[
g_f=\left\lfloor\frac{\log_{10}f}{0.10}\right\rfloor,\qquad
g_B=\left\lfloor\frac{\log_{10}B_m}{0.10}\right\rfloor.
\]

`condition_group = material | temperature | waveform | g_f | g_B`。完全重复记录共享同一组。Q1 使用 `near_shape_group` 做主分组并做留一材料压力测试；Q2/Q3/Q4 使用 `condition_group` 做主分组。若 5 折任一验证折缺少必要类别，折数按 5→4→3 依次降低，但不得退回无分组随机切分。

## 4. 各问模型主线

| 问题 | 最简单合理 Baseline | 主候选/分析路线 | 与后问的数据流 |
|---|---|---|---|
| Q1 | `wave-v1` 形状特征 + 标准化多项逻辑回归 | HistGradientBoostingClassifier；随机森林仅作挑战者 | 冻结波形特征；分类本身不作为 Q4 训练标签替代物 |
| Q2 | 材料1正弦波的传统对数 Steinmetz 回归 | 乘性温度二次修正；温度交互只在失败条件触发后进入 S4 | 冻结 $B_m$、误差口径和温度效应认识 |
| Q3 | 各因素分层描述统计 | 对 $\log P_v$ 的可解释加性/交互回归，控制 $\log f$ 与 $\log B_m$，组 Bootstrap | 解释 Q4 分组误差和 Q5 条件，不把关联当因果 |
| Q4 | 带材料/温度/波形的对数线性 Ridge | HistGradientBoostingRegressor；随机森林仅作挑战者 | 唯一进入 Q5 的损耗预测接口 |
| Q5 | 以实测工况点的严格 OOF 损耗做非支配解 | 验证折区域一致性、500 次工况组 Bootstrap 与全量模型一致性诊断；连续扩展需新 Gate | 输出损耗—$fB_m$ 权衡和数据域内、绑定具体波形的推荐工况 |

主候选均来自现有 scikit-learn/SciPy 环境。随机森林和梯度提升不会同时堆叠；它们只在同一折、同一特征和同一指标下竞争，最终保留一个胜者或回退 Baseline。

## 5. 验证与模型选择总则

### 5.1 固定折与嵌套边界

- 外层：最多 5 折 `StratifiedGroupKFold`（分类）或 `GroupKFold`（回归），只用于无偏 OOF 评价。
- 内层：3 折分组验证，只在外层训练部分做有限超参数选择。
- 所有缩放、编码、缺失保护和学习型特征处理放入 Pipeline，在折内拟合。
- 保存每条训练记录的 `row_id/group_id/fold/y_true/y_pred/model_id`；不只保存折均值。
- 最终模型选择结束后才用附件一全量重拟合；附件二、三只预测一次。

### 5.2 主指标

| 任务 | 主指标 | 辅助指标 |
|---|---|---|
| Q1 | Macro-F1（越大越好） | Accuracy、Balanced Accuracy、逐类 Recall、混淆矩阵 |
| Q2 | OOF RMSLE（越小越好） | MAE、RMSE、MAPE、中位绝对百分比误差、分温度残差 |
| Q3 | 调整后的效应/交互稳定性 | OOF log-RMSE、Bootstrap 95% 区间、移除因素后的增量误差 |
| Q4 | OOF RMSLE（越小越好） | MAE、RMSE、MAPE、$R^2$、分材料/波形/温度误差 |
| Q5 | 严格 OOF 非支配性与验证折区域支持 | OOF/full 一致性、500 次工况组 Bootstrap、观测损耗 Pareto 诊断、边界/峰值口径敏感性 |

回归指标统一引用共享合同：RMSLE 使用自然对数 `log1p`，MAPE 分母下限为 `1 W/m³`，$R^2$ 在原始 W/m³ 尺度计算。MAPE 只作辅助指标。模型比较使用相同 OOF 样本的成对损失；置信区间按 `condition_group` 做簇 Bootstrap，而不是逐行独立重采样。

### 5.3 升级和回退规则

- Baseline 未跑通五问闭环时，不运行主候选。
- Q1 主候选只有在 Macro-F1 的成对提升为正且任一类别 Recall 不比 Baseline 下降超过 0.02 时才替代 Baseline；差异很小时选更简单者。
- Q2 温度修正只有在相同外层折上降低 RMSLE，且至少 3/4 温度层不劣化时，才能声称改善；否则保留传统 SE 并触发有限温度交互候选。
- Q4 主候选需比 Ridge Baseline 的 RMSLE 相对降低至少 2%，且每个 `n≥100` 并覆盖至少 3 个外层折的主要子组 RMSLE 不恶化超过 10%；否则回退 Ridge 或更简单的胜者。
- 任何候选若出现非有限预测、负损耗、折间极不稳定、单次运行超出预算或无法重现，立即失败。
- Q5 若 Q4 未优于常数/分组中位数、候选未同时位于 OOF/full Pareto、OOF 残差或 full/OOF 差超过预定 P90，或其区域未达到折级与 Bootstrap 稳定门槛，只报告 Pareto 区域和端点，不给单点“最优”。

## 6. Q5 可执行联合可行域

主路线不使用逐变量 min/max 的笛卡尔积。Q5 的决策对象正式定义为附件一中的“实测工况点”而不是抽象五元组：

\[
c_i=(\text{row\_id},\text{source locator},\text{waveform SHA-256},T_i,f_i,w_i,B_{m,i},m_i,B_{i,0:1023},\phi_i),
\]

其中 $\phi_i$ 是 Q4 实际消费的完整 `wave-v1` 特征。来源文件 SHA-256、工作表、Excel 行号、原始波形规范化 SHA-256、全部 Q4 输入特征、模型/配置哈希一起构成可复算身份。$g_i=(T_i,f_i,w_i,B_{m,i},m_i)$ 只作为五因素汇总，不宣称能脱离波形轮廓唯一决定损耗。

候选集合 $\mathcal X_{obs}$ 是题面名义频率域内的上述实测点；完全重复状态只在保留所有来源映射后折叠。令 $k(i)$ 为唯一留出候选 $i$ 的 Q4 外层模型，则主目标为：

\[
\min F_{OOF}(c_i)=\left(\widehat P_{v,i}^{\,OOF},-f_iB_{m,i}\right),
\qquad \widehat P_{v,i}^{\,OOF}=M_{-k(i)}(c_i).
\]

主 Pareto、端点和膝点只用严格 OOF 损耗构造。Q4 全量模型预测另建 `full-fit reference Pareto`，只用于最终重拟合参考和一致性诊断，不参与折外投票。候选只有同时位于 OOF 与 full-fit Pareto，且以下两项都不超过参照分布 P90，才有资格成为单点推荐：

\[
d_i=|\log(1+\widehat P_{v,i}^{full})-\log(1+\widehat P_{v,i}^{OOF})|,
\]

\[
r_i=|\log(1+P_{v,i})-\log(1+\widehat P_{v,i}^{OOF})|.
\]

参照分布按材料×波形分层，`n<100` 时回退全局。观测 $P_v$ 只用于残差和“模型 Pareto vs 观测损耗 Pareto”诊断，不替代题目要求的 Q4 模型目标。

折级稳定性中，每个外层模型只能评价其验证折候选。`q5-region-v1` 由材料、波形、温度以及在 $\mathcal X_{obs}$ 上不看损耗预先计算的频率/$B_m$ 四分位箱组成，重复边界合并并写入 manifest。区域需在至少 $\lceil0.6K\rceil$ 个验证折的折级 Pareto 中出现，正常 5 折即至少 3 折。另对严格 OOF 候选表执行 500 次 `condition_group` 簇 Bootstrap；区域在至少 400 次有效重采样中有候选时才评价，条件 Pareto 入选率至少 50%。由此得到的区间称“95% condition-group cluster bootstrap percentile interval”；5 个折模型的预测范围若保留，只称“重拟合扰动范围”，不得称置信区间。

膝点仍按两目标归一化后到理想点的欧氏距离确定，并公开两个端点。任一双 Pareto、P90、折级或 Bootstrap 门槛失败时，只报告稳定因素区域、频率/$B_m$ 区间和端点，不给唯一推荐；所有单点必须表述为“该实测波形轮廓下的推荐工况”。连续 $f/B_m$ 或合成波形扩展默认关闭，若以后需要必须另建合同并重新过 Gate。

## 7. 计算预算与完成性

当前机器没有可验证 GPU，按 CPU 路线设计，这比 G2 的单张 A800 上限更保守。

| 模块 | 数据规模 | 预算上限 | 并行策略 |
|---|---:|---:|---|
| 统一读取与 `wave-v1` 特征 | 12,880×1,024 输入点 | 20 min，缓存一次 | NumPy 向量化；只读原件 |
| Q1 Baseline + 有限候选嵌套验证 | 12,400×约 30 特征 | 95 min | 最多使用物理核数-1 |
| Q2 方程拟合与比较 | 1,067 条 | 45 min | 单进程即可 |
| Q3 效应模型 + 500 次簇 Bootstrap | 12,400 条 | 120 min | 可并行 Bootstrap |
| Q4 Baseline + 有限候选嵌套验证 | 12,400×约 30 特征 | 260 min | 限定候选数和线程；单作业≤120 min |
| Q5 严格 OOF Pareto + 折级区域/Bootstrap 稳健性 | ≤12,400 候选 | 45 min | 复用 Q4 OOF；向量化非支配筛选，不新增模型拟合 |

S3 只跑 Baseline，目标 2 小时内形成五问闭环；S4 候选与稳健性串行总预算不超过 8 小时，单个作业硬上限 120 分钟。任何任务达到上限就保存日志、终止该候选并回退，不能让复杂模型阻断全题。

## 9. 风险—控制对应

| 风险 | 已冻结控制 | 失败时回退 |
|---|---|---|
| 测试集调参 | 附件二/三在模型冻结后单次预测 | 删除受污染实验并重做附件一验证 |
| 完全/近重复泄漏 | 同组同折、近形状签名、工况分组 | 降低折数，不退回随机行切分 |
| 频率边界不一致 | 原值保留；Q5 名义域主结果+实测域敏感性 | 只报告两种域共同稳定结论 |
| `B_m` 口径 | `max(abs(B))` 主口径、`B_pp/2` 敏感性 | 若结论变化，双口径并列且不下单一结论 |
| Q1 学到辅助字段代理 | 主模型只用 B 派生形状；辅助字段仅消融 | 回退形状特征 Baseline |
| 长尾损耗 | log 目标、原/对数/相对指标并报 | 回退稳健线性或分层中位数基线 |
| Q3 因果夸大 | 只作调整后关联，簇 Bootstrap | 降级为描述性分层结论 |
| Q5 隐藏波形或训练内极值 | 实测点完整身份、严格 OOF 主 Pareto、双 Pareto/P90 拒绝、折级区域与簇 Bootstrap | 只给稳定实测区域和端点，不做连续扩展或唯一推荐 |
