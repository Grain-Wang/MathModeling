# 科研图表配色指南 2（TPAMI 简洁六色）

本项目在不需要五种以上独立配色时，默认参考 [AMFE 科研配色色板 109](https://color.amfe.space/#/palette/109)。该页面收录的是一组 IEEE TPAMI 论文案例配色，由蓝、玫红、灰三种主体色及对应的三种浅色组成，适合白底上的模型比较、折线图、散点图、柱状图、箱线图、置信区间和流程图。

> 这是一套论文案例配色，不是 IEEE TPAMI 投稿的强制规范。使用时以数据语义、可读性和无障碍要求为先。

## 1. 两份配色指南的选择规则（强制）

- 单张图需要 **1–5 种独立配色**时，使用本指南 [`figure_color2_guide.md`](./figure_color2_guide.md)，保持画面简洁统一。
- 单张图需要 **五种以上，即至少 6 种独立配色**，而且各类别确实需要较大区分度时，使用 [`figure_color1_guide.md`](./figure_color1_guide.md) 的 Lancet 11 色方案。
- “配色数量”按图例中需要独立识别的语义系列计算，不按柱子、散点、节点或样本总数计算。置信区间、背景带、网格线、缺失值和边框不计入独立配色数量。
- 对象虽然超过 5 个，但可以归并为不超过 5 种状态或类型时，仍使用本指南，并通过标签、点型、线型或分面区分对象。
- 同一张图不得混用两份指南的主体色板。切换指南后，同一语义在相关面板和配套图中必须保持同色。

快速判断：

```text
独立语义系列 ≤ 5
└─ 使用 figure_color2_guide.md

独立语义系列 > 5
├─ 每一类都必须靠颜色区分 → 使用 figure_color1_guide.md
└─ 可以归并、分面或突出重点 → 仍使用 figure_color2_guide.md
```

## 2. 强制原则

1. **先确定语义，再分配颜色。** 主方法、重点对照和中性基线优先对应蓝、玫红和灰。
2. **深色承载数据，浅色承载范围。** 线、点、文字和小标记使用深色；置信区间、背景带和大面积模块使用对应浅色。
3. **颜色不是唯一编码。** 关键分组同时使用文字标签、线型、点型、边框或纹理中的至少一种。
4. **同一语义全篇同色。** 同一模型、方案、区域、变量或状态不得在不同面板中重新分配颜色。
5. **突出重点，弱化基线。** 核心结论使用蓝或玫红，背景组和辅助信息使用灰色。
6. **连续变量使用连续色阶。** 不得把六个色值按来源顺序机械拼接成连续热力图。
7. **最终尺寸验收。** 必须在论文实际排版尺寸、灰度模式和常见色觉缺陷模拟下检查。

## 3. 标准色板

### 3.1 来源页面原始六色

| 序号 | HEX | RGB | 建议角色 |
|---:|---|---|---|
| 1 | `#F0FAFB` | `240, 250, 251` | 蓝色系列的置信区间、冷色背景 |
| 2 | `#FEF0F0` | `254, 240, 240` | 玫红系列的置信区间、暖色背景 |
| 3 | `#EEF3F7` | `238, 243, 247` | 中性背景带、表格或流程模块底色 |
| 4 | `#7189B1` | `113, 137, 177` | 默认主色、主模型、核心曲线 |
| 5 | `#E36281` | `227, 98, 129` | 重点对照、强调结果、警示系列 |
| 6 | `#A39F9E` | `163, 159, 158` | 基线、辅助方法、非重点系列 |

复制用色值：

```text
#F0FAFB, #FEF0F0, #EEF3F7, #7189B1, #E36281, #A39F9E
```

### 3.2 三组明暗配对

| 色彩家族 | 浅色 | 深色 | 默认用途 |
|---|---|---|---|
| 蓝色 | `#F0FAFB` | `#7189B1` | 主方法、主结果、输入或核心模块 |
| 玫红 | `#FEF0F0` | `#E36281` | 重点对照、异常、需要注意的结果 |
| 中性灰 | `#EEF3F7` | `#A39F9E` | 基线、参考、背景信息 |

浅色与深色之间应保持语义配对。例如，`#7189B1` 曲线的置信区间使用 `#F0FAFB`，不要改用 `#FEF0F0`。

### 3.3 项目扩展中间色

当单图确需 4–5 种独立配色时，可在对应明暗端点之间插值得到以下中间色：

| HEX | RGB | 来源 | 使用限制 |
|---|---|---|---|
| `#B1C2D6` | `177, 194, 214` | 蓝色明暗端点的中间色 | 配深色边框、点型或线型 |
| `#F1A9B9` | `241, 169, 185` | 玫红明暗端点的中间色 | 配深色边框、点型或线型 |
| `#C9C9CB` | `201, 201, 203` | 灰色明暗端点的中间色 | 仅作次要系列或填充 |

这些中间色是本项目为扩展 4–5 系列图而计算的辅助色，不属于来源页面列出的原始六色。

### 3.4 辅助中性色

| 用途 | HEX |
|---|---|
| 正文、坐标轴、外框 | `#2F2F2F` |
| 次要文字、参考线 | `#7A7A7A` |
| 网格线、非重点连接线 | `#D9D9D9` |
| 画布背景 | `#FFFFFF` |

图内文字原则上放在色块外。确需放入色块时，应单独检查文字与底色的对比度。

## 4. 按系列数量分配颜色

| 独立系列数 | 推荐主体色 |
|---:|---|
| 1 | `#7189B1` |
| 2 | `#7189B1`, `#E36281` |
| 3 | `#7189B1`, `#E36281`, `#A39F9E` |
| 4 | `#7189B1`, `#E36281`, `#A39F9E`, `#B1C2D6` |
| 5 | `#7189B1`, `#E36281`, `#A39F9E`, `#B1C2D6`, `#F1A9B9` |
| >5 | 改用 [`figure_color1_guide.md`](./figure_color1_guide.md) |

- 单系列默认使用 `#7189B1`，不要为同一序列制造无意义的渐变色。
- 两组重点比较使用蓝与玫红；若第二组只是普通基线，则使用蓝与灰。
- 三组比较默认对应“主方法—重点对照—中性基线”。
- 四至五组必须增加不同点型、线型、纹理或直接标签；中间色不得单独用于白底细线。
- 若类别具有明确的好坏、大小或先后顺序，不使用本表的无序分配方式，应改用连续或发散色阶。

## 5. 按数据关系选色

### 5.1 无序类别

使用第 4 节的离散分配。颜色只表示类别身份，不暗示数值大小。图例顺序应与正文叙述和面板顺序一致。

### 5.2 有序等级或连续数值

每次只选择一个色彩家族，从浅到深表示从低到高：

```text
蓝色：#F0FAFB → #B1C2D6 → #7189B1
玫红：#FEF0F0 → #F1A9B9 → #E36281
灰色：#EEF3F7 → #C9C9CB → #A39F9E
```

- 连续变量使用连续插值和完整色条；离散等级使用清晰分箱及边界说明。
- 多个面板比较同一变量时，必须固定色条范围。
- 灰色色阶只用于中性强度或参考量，不用于需要醒目识别的核心结论。
- 若精确数值判断比风格统一更重要，优先使用经过感知均匀性验证的连续色图，再把本色板用于标注和重点系列。

### 5.3 围绕基准值的发散数据

仅当零值、均值、目标值或阈值具有明确语义时，使用蓝—白—玫红发散色：

```text
低值：#7189B1 → #B1C2D6 → #F0FAFB
中点：#FFFFFF
高值：#FEF0F0 → #F1A9B9 → #E36281
```

色条必须直接标明中点数值及其含义。数据范围不对称时，应以语义中点归一化，而不是按最小值和最大值简单平分。

### 5.4 默认语义映射

| 语义 | 线、点或边框 | 区间或背景 |
|---|---|---|
| 主方法、核心结果 | `#7189B1` | `#F0FAFB` |
| 重点对照、异常、警示 | `#E36281` | `#FEF0F0` |
| 基线、参考、非重点 | `#A39F9E` | `#EEF3F7` |
| 缺失、不适用 | `#7A7A7A` | `#D9D9D9` |

玫红不自动代表“统计显著”或“失败”，蓝色也不自动代表“最优”。颜色含义必须由图例或图注明确说明。

## 6. 不同图型的具体规则

### 折线图

- 单图最多显示 5 条需要独立识别的主要曲线。
- 主曲线使用 `#7189B1` 实线；重点对照使用 `#E36281`；普通基线使用 `#A39F9E`。
- 四至五条曲线时，同时使用 `实线/虚线/点划线` 与 `圆/方/三角` 标记。
- 置信区间使用对应浅色或主体色的 `alpha=0.15–0.25` 填充，不另分配类别色。
- 尽量在曲线末端直接标注名称，减少读者反复查找图例。

### 柱状图与箱线图

- 柱体或箱体使用主体色填充，并增加深色边框。
- 浅色只能用于成组背景、误差范围或有深色边框的大面积填充。
- 误差线统一使用 `#2F2F2F` 或 `#7A7A7A`；图注说明误差定义。
- 能展示原始样本时，在箱线图或均值图上叠加半透明散点。

### 散点图

- 主组使用 `#7189B1`，重点对照使用 `#E36281`，背景样本降为灰色。
- 点密集时降低透明度，并使用点型、轮廓或分面减轻遮挡。
- 连续变量必须使用单向连续色阶和色条，不得循环使用六个离散色。
- 重点样本可加深色描边，不能只依靠更大的点来表示重要性。

### 热力图、等高线图与地图

- 非负强度使用单一色彩家族；正负变化或高于/低于基准使用蓝—白—玫红发散色。
- 色条必须包括变量名、单位、刻度和中点。
- 缺失值统一使用灰色，并在图例中标注，不得让缺失值与零值共用一种颜色。
- 多个面板比较时固定颜色范围；不得让每个面板自动缩放色阶。

### 流程图、技术路线图与机制图

- 核心模块使用浅蓝底 `#F0FAFB` 和蓝色边框 `#7189B1`。
- 警示或重点模块使用浅玫红底 `#FEF0F0` 和玫红边框 `#E36281`。
- 辅助模块使用 `#EEF3F7` 底和 `#A39F9E` 边框。
- 箭头默认使用深灰；颜色编码模块类型或状态，不编码装饰层级。
- 整图尽量只使用三组明暗配对，避免每个节点一种颜色。

## 7. 可访问性与出版检查

### 必须做到

- 关键差异至少由“颜色 + 另一种视觉通道”共同表达。
- 用第一色盲、第二色盲和第三色盲模拟检查；若蓝、玫红或灰在特定背景下难以区分，增加线型、点型、边框或直接标签。
- 转为灰度后检查主次关系、曲线交叉点和重点区域是否仍然可辨。
- 在论文最终栏宽下查看，不以绘图软件中的放大效果代替排版检查。
- 浅色块必须有深色边框；浅色不得承担小字号文字或细线。
- 坐标轴、单位、图例、样本量、误差定义和色条含义齐全。

### 禁止做法

- 仅靠蓝/玫红区分关键类别而不提供任何冗余编码。
- 在白底上使用 `#F0FAFB`、`#FEF0F0` 或 `#EEF3F7` 绘制细线和小点。
- 为了“更丰富”给每根柱、每个节点随机分配颜色。
- 在同一图内混入第一指南的高饱和多色方案。
- 使用三维柱状图、渐变阴影、发光或大面积高饱和背景。
- 截断坐标轴却不标记，或用不同色阶范围夸大面板差异。

## 8. 代码模板

### Python / Matplotlib

```python
from matplotlib.colors import LinearSegmentedColormap, TwoSlopeNorm

TPAMI_6 = [
    "#F0FAFB", "#FEF0F0", "#EEF3F7",
    "#7189B1", "#E36281", "#A39F9E",
]

CAT_2 = ["#7189B1", "#E36281"]
CAT_3 = ["#7189B1", "#E36281", "#A39F9E"]
CAT_5 = ["#7189B1", "#E36281", "#A39F9E", "#B1C2D6", "#F1A9B9"]

BLUE_PAIR = {"light": "#F0FAFB", "dark": "#7189B1"}
ROSE_PAIR = {"light": "#FEF0F0", "dark": "#E36281"}
GRAY_PAIR = {"light": "#EEF3F7", "dark": "#A39F9E"}

blue_cmap = LinearSegmentedColormap.from_list(
    "tpami_blue", ["#F0FAFB", "#B1C2D6", "#7189B1"]
)
rose_cmap = LinearSegmentedColormap.from_list(
    "tpami_rose", ["#FEF0F0", "#F1A9B9", "#E36281"]
)
diverging_cmap = LinearSegmentedColormap.from_list(
    "tpami_diverging",
    ["#7189B1", "#B1C2D6", "#F0FAFB", "#FFFFFF",
     "#FEF0F0", "#F1A9B9", "#E36281"],
)

# 仅在 0 是有意义的中心值时使用
diverging_norm = TwoSlopeNorm(vmin=-1, vcenter=0, vmax=1)
```

### R / ggplot2

```r
tpami_6 <- c(
  "#F0FAFB", "#FEF0F0", "#EEF3F7",
  "#7189B1", "#E36281", "#A39F9E"
)

cat_2 <- c("#7189B1", "#E36281")

# 离散类别
p + scale_colour_manual(values = cat_3)

# 蓝色连续色阶

  colours = c("#F0FAFB", "#B1C2D6", "#7189B1")
)

# 以 0 为中心的发散色阶
p + scale_fill_gradient2(
  low = "#7189B1", mid = "#FFFFFF", high = "#E36281", midpoint = 0
)
```
