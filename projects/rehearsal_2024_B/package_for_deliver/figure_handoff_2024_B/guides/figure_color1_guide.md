# 科研图表配色指南（Lancet 11 色）

> **指南选择规则：** 只有当单张图必须区分五种以上（即至少 6 种）独立配色时才使用本指南；需要 1–5 种独立配色时，默认使用更简洁统一的 [`figure_color2_guide.md`](./figure_color2_guide.md)。

本项目的科研图默认参考 [AMFE 科研配色色板 106](https://color.amfe.space/#/palette/106)。该页面收录的是一组来自 Lancet 论文案例的 11 色配色，适合白底上的多组比较、折线图、散点图、箱线图和分组统计图。

> 这是一套论文案例配色，不是 Lancet 投稿的强制规范。使用时以数据语义、可读性和无障碍要求为先；若颜色不足以区分数据，必须增加线型、点型、纹理或直接标签，不得为了保持色板完整而牺牲信息表达。

## 1. 强制原则

1. **先确定数据关系，再选择颜色。** 无序类别使用离散色；有序数值使用单向渐变；围绕零值、基准值或阈值的数据使用发散色。
2. **颜色不是唯一编码。** 关键分组必须同时使用文字标签、线型、点型、边框或纹理中的至少一种进行冗余编码。
3. **同一语义全篇同色。** 同一模型、方案、区域、变量或状态在所有图中保持同一颜色；不得因面板不同而重新分配。
4. **突出结论，而不是平均用色。** 主方法或核心结果使用最醒目的主色；基线、背景组和辅助信息使用灰色或降低饱和度。
5. **浅色只作填充。** `#A1D8E8`、`#D0E2C0`、`#FDED95`、`#FFC1A6` 不单独用于白底细线、小点或小字号文字。
6. **不使用彩虹色阶。** 连续变量不得把 11 个颜色机械拼接成彩虹热力图。
7. **最终尺寸验收。** 图必须在论文实际排版尺寸、灰度模式和常见色觉缺陷模拟下检查；缩小后仍应读得出主要结论。

| 4 | `#67A583` | `103, 165, 131` | 可行、改善、通过、正向状态 |

| 6 | `#D0E2C0` | `208, 226, 192` | 正向区间浅填充 |

```text
#7B95C6, #49C2D9, #A1D8E8, #67A583, #A2C986, #D0E2C0, #FDED95, #FFC1A6, #F59C7C, #F47254, #C85E62
```

### 辅助中性色

以下颜色不属于来源色板，但用于保证论文版面的层次和可读性：

| 用途 | HEX |
|---|---|
| 正文、坐标轴、外框 | `#2F2F2F` |
| 次要文字、基线 | `#7A7A7A` |
| 网格线、非重点连接线 | `#D9D9D9` |
| 浅灰背景带 | `#F2F2F2` |
| 画布背景 | `#FFFFFF` |

背景组或基线优先使用中性灰，不要占用一个高辨识度颜色。图内文字原则上放在色块外；确需放入色块时，应单独检查文字与底色的对比度。

## 3. 按数据关系选色

### 3.1 无序类别或多模型比较

不要直接取原色板的前 `N` 个颜色，因为相邻的蓝青色或橙红色可能过于接近。按系列数量优先使用：

| 系列数 | 推荐颜色 |
|---:|---|
| 1 | `#7B95C6` |
| 2 | `#7B95C6`, `#F47254` |
| 3 | `#7B95C6`, `#67A583`, `#F47254` |
| 4 | `#7B95C6`, `#49C2D9`, `#67A583`, `#F47254` |
| 5 | `#7B95C6`, `#49C2D9`, `#67A583`, `#F59C7C`, `#C85E62` |

- 两组比较时，主方法用 `#7B95C6`，重点对照用 `#F47254`；若对照只是背景参照，则改用 `#7A7A7A`。
- 三组比较时，建议固定为主方法 `#7B95C6`、可行/改善方案 `#67A583`、对照/警示方案 `#F47254`。
- 四组及以上必须再叠加不同点型或线型，并优先在曲线末端直接标注名称。
- 超过五个无序类别时，优先分面、合并次要类别或突出“重点 + 其他”。确需展示 6–11 类时，可以从完整色板中取色，但必须逐图进行色觉缺陷和灰度检查。

### 3.2 有序等级或连续数值

连续数据只选择一个明度方向基本连续的子色阶：

```text
冷色 3 级：#A1D8E8 → #49C2D9 → #7B95C6
绿色 3 级：#D0E2C0 → #A2C986 → #67A583
暖色 5 级：#FDED95 → #FFC1A6 → #F59C7C → #F47254 → #C85E62
```

- 低值到高值必须对应浅色到深色，并在整篇论文中保持方向一致。
- 连续变量使用连续插值和完整色条；离散等级使用清晰分箱及边界说明。
- 若精确数值判断比风格统一更重要，优先使用经过感知均匀性验证的连续色图，再把本色板用于标注和重点系列。

### 3.3 围绕基准值的发散数据

只有当零值、目标值、均值或阈值具有明确含义时才使用发散色：

```text
低值：#7B95C6 → #49C2D9 → #A1D8E8
中点：#F7F7F7
高值：#FFC1A6 → #F59C7C → #F47254 → #C85E62
```

色条必须标出中点的数值与含义。若数据范围不对称，应让色阶以语义中点归一化，而不是简单按最小值和最大值平分。

### 3.4 状态和语义色

建议在流程图、机制图、地图和决策图中固定以下语义：

| 语义 | 颜色 |
|---|---|
| 数据输入、主模型、核心方案 | `#7B95C6` |
| 次级过程、辅助信息 | `#49C2D9` 或浅灰 |
| 可行、改善、验证通过 | `#67A583` |
| 提醒、临界、待检查 | `#FDED95`，配 `#2F2F2F` 边框与文字 |
| 警示、高负荷、显著偏离 | `#F47254` |
| 风险、失败、异常 | `#C85E62` |
| 未知、缺失、不适用 | `#D9D9D9` |

红色不自动代表“统计显著”，绿色也不自动代表“最优”。图例和图注必须写明颜色的实际含义。

## 4. 不同图型的具体规则

### 折线图

- 单图建议不超过 5 条主要曲线。
- 主曲线使用 `#7B95C6` 实线；对照曲线根据重要性使用 `#F47254` 或 `#7A7A7A`。
- 多条曲线同时用 `实线/虚线/点划线` 与 `圆/方/三角` 标记区分。
- 置信区间使用与曲线同色的浅色或 `alpha=0.15–0.25` 填充，不另分配类别色。
- 不用浅黄色、浅绿色绘制白底细线。

### 柱状图与箱线图

- 柱体或箱体使用色板填充，并增加 `#2F2F2F` 或同色深边框。
- 误差线统一用深灰；图注说明误差条代表标准差、标准误还是置信区间。
- 有自然顺序的组按冷色、绿色或暖色子色阶排列；无序组使用离散取色方案。
- 能显示原始样本时，在箱线图或均值图上叠加半透明散点，避免只展示汇总量。

### 散点图、聚类图与 UMAP

- 点较密时降低透明度，并使用轮廓、点型或分面减轻遮挡。
- 类别不超过 5 个时采用离散取色方案；类别较多时必须提供直接标签或编号映射。
- 连续变量必须使用单向连续色阶和色条，不得循环使用 11 个离散色。
- 重点样本可以用 `#F47254` 或 `#C85E62` 加描边，其余样本降为灰色。

### 热力图、等高线图与地图

- 非负强度使用单向子色阶；正负变化或高于/低于基准使用发散色阶。
- 色条必须显示变量名、单位、刻度和中点；多个面板比较时固定色条范围。
- 缺失值统一使用浅灰，并在图例中明确标注，不得让缺失值与零值共用一种颜色。
- 面积大小会影响颜色感知；地图中的小区域应增加边界线或标签。

### 流程图、技术路线图与机制图

- 颜色编码模块类型或状态，不编码装饰层级。
- 同类节点保持同色；层级通过位置、字号和边框表达。
- 整张图以 1 个主色、1 个状态色和中性灰为主，风险或结论节点才使用暖色强调。
- 箭头默认使用深灰，只有需要表达状态或方向差异时才着色。

## 5. 可访问性与出版检查

### 必须做到

- 关键差异至少由“颜色 + 另一种视觉通道”共同表达。
- 用第一色盲、第二色盲和第三色盲模拟检查；若两组难以区分，先改线型、点型或标签，再考虑换色。
- 转为灰度后检查主次关系、曲线交叉点和重要区域是否仍可辨认。
- 在论文最终栏宽下查看，不以绘图软件中的放大效果代替排版检查。
- 坐标轴、单位、图例、样本量、误差定义和色条含义齐全。
- 同一组比较图使用相同坐标范围、颜色映射和图例顺序。

### 禁止做法

- 仅靠红/绿区分两组或表示好/坏。
- 在白底上使用浅黄色细线或无边框浅色色块。
- 为了“更丰富”给每根柱、每个节点随机分配颜色。
- 使用三维柱状图、渐变阴影、发光、重投影或大面积高饱和背景。
- 截断坐标轴却不显式标记，或让不同面板使用不同色阶范围造成夸大。
- 手工修改单个数据点的颜色来强化并不存在的结论。

## 6. 代码模板

### Python / Matplotlib

```python
from matplotlib.colors import LinearSegmentedColormap, TwoSlopeNorm

LANCET_11 = [
    "#7B95C6", "#49C2D9", "#A1D8E8",
    "#67A583", "#A2C986", "#D0E2C0",
    "#FDED95", "#FFC1A6", "#F59C7C",
    "#F47254", "#C85E62",
]

CAT_3 = ["#7B95C6", "#67A583", "#F47254"]
CAT_5 = ["#7B95C6", "#49C2D9", "#67A583", "#F59C7C", "#C85E62"]

cool_cmap = LinearSegmentedColormap.from_list(
    "lancet_cool", ["#A1D8E8", "#49C2D9", "#7B95C6"]
)
warm_cmap = LinearSegmentedColormap.from_list(
    "lancet_warm", ["#FDED95", "#FFC1A6", "#F59C7C", "#F47254", "#C85E62"]
)
diverging_cmap = LinearSegmentedColormap.from_list(
    "lancet_diverging",
    ["#7B95C6", "#49C2D9", "#A1D8E8", "#F7F7F7",
     "#FFC1A6", "#F59C7C", "#F47254", "#C85E62"],
)

# 仅在 0 是有意义的中心值时使用
diverging_norm = TwoSlopeNorm(vmin=-1, vcenter=0, vmax=1)
```
